# AI QA Testing Project

一个用于测试开发实习准备的 FastAPI 项目，包含业务接口开发与完整的 Pytest 自动化测试覆盖。

## 🛠 Tech Stack
- Python 3.13
- FastAPI (Web Framework)
- Pytest (Automation Testing)

## 🚀 How to Run
1. 安装依赖: `pip install -r requirements.txt`
2. 启动服务: `uvicorn main:app --reload`
3. 查看接口文档: 访问 `http://127.0.0.1:8000/docs`

## 🧪 How to Test
运行自动化测试: `pytest -v`
